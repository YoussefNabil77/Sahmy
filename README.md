# سهمي (Sahmy) 📈

مشروع بسيط عبارة عن لوحة تحكم (Dashboard) لمتابعة البورصة المصرية (EGX). الواجهة مبنية بـ React و Tailwind وبتدعم الـ Dark Mode الافتراضي عشان تكون مريحة للعين ومناسبة لجو التداول.

## المشكلة في بيانات البورصة المصرية (إزاي بنجيب الداتا؟)

لو حاولت تسحب بيانات من موقع البورصة الرسمي (egx.com.eg) بـ `fetch` أو `curl` عادي، هتلاقي الموقع بيعملك Block فوراً بسبب حماية F5 BIG-IP اللي بتطلب تنفيذ JavaScript Challenge.

عشان نحل المشكلة دي، عملت Proxy Server صغير في فولدر `server/`. السيرفر ده شغال بـ Node.js وبيستخدم **Playwright** عشان يفتح متصفح Chromium حقيقي في الخلفية، يتخطى الحماية، ويسحب البيانات ويعملها Caching كل 5 دقايق عشان منعملش لود (Load) على الموقع وتجنباً لأي حظر.

## إيه الحقيقي وإيه الـ Mock؟

بما إن مش كل البيانات متاحة للعامة على موقع البورصة، التطبيق بيخلط بين داتا حقيقية وداتا تجريبية:

- **البيانات الحقيقية (بتيجي من الموقع):** المؤشرات (EGX30/70/100)، الأسعار الحالية للأسهم وتغييراتها، حركة القطاعات، والأخبار.
- **البيانات التجريبية (Mock):** هيكل الملكية، السيولة التفصيلية لآخر 14 يوم، والنتائج المالية. (هتلاقي دايماً جنب الأرقام دي بادج صغير مكتوب عليه "بيانات تجريبية" عشان متتلخبطش وتفتكرها أرقام حقيقية).

## عشان تشغل المشروع عندك (How to run)

المشروع متقسم لجزئين، محتاج تشغلهم مع بعض:

**1. تشغيل الـ Proxy Server (الباك إند):**
```bash
cd server
npm install
npx playwright install chromium  # بنعملها أول مرة بس عشان يحمل المتصفح
npm start
```
كده السيرفر هيشتغل على بورت 3001.

**2. تشغيل الـ Frontend:**
افتح تيرمينال تاني في المسار الرئيسي بتاع المشروع واكتب:
```bash
npm install
npm run dev
```
افتح المتصفح على `http://localhost:5173`. التطبيق متظبط إنه يكلم بورت 3001 تلقائياً عن طريق Vite proxy.

## الدبلوي (Deployment)

المشروع جاهز ومضاف ليه ملف `vercel.json` عشان يترفع مباشرة على Vercel بخاصية الـ **Vercel Services**. 
يعني مجرد ما ترفع الـ Repo، Vercel هيفهم إن فولدر `server/` عبارة عن باك إند منفصل وهيعمله توجيه (Routing) على مسار `/api` لوحده من غير أي وجع دماغ في الـ CORS.

## إخلاء مسؤولية
التطبيق ده معمول لأغراض برمجية وتعليمية بس. الداتا معتمدة على الـ Web Scraping وممكن تتأخر شوية عن السوق الفعلي، عشان كده متعتمدش عليها في اتخاذ أي قرارات مالية أو استثمارية.
